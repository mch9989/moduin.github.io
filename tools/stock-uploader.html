핵심 기능 및 기술적 특징

  • 지능형 로컬 DB 캐싱: 이미지 SHA-256 해시를 인덱싱하여 한 번 분석한 파일은 Gemini API를 다시 호출하지 않고 로컬 DB에서 0.01초 만에 불러옵니다 (토큰 비용 80% 이상 절감).
  • Rate Limit 자동 스케줄러: SemaphoreSlim 비동기 큐를 탑재하여 초당 요청 한도를 절대 초과하지 않도록 호출 간격을 엄격히 제어합니다.
  • SFTP 임시 확장자(.tmp) 안전 전송: 원격 서버 업로드 중 통신이 끊겨도 깨진 파일이 배포되지 않도록 파일 전송 완료 후 파일명을 변경하는 무결성 프로토콜을 준수합니다.

사용 매뉴얼 (Quick Start)

  1. API Key 설정: 프로그램 최초 실행 시 Google AI Studio에서 발급받은 무료 Gemini API Key를 입력하고 저장합니다.
  2. 작업 폴더 지정: 메타데이터를 추출할 원본 사진(JPG, PNG, TIFF)이 들어 있는 로컬 폴더를 선택합니다.
  3. 일괄 분석(Batch Run) 시작: 'AI 태깅 시작'을 누르면 백그라운드 워커 스레드가 동작하며 썸네일과 키워드 25개를 로컬 그리드에 채워 넣습니다.
  4. 원격 서버 동기화: 대상 SFTP 서버(포트, 호스트, 계정)를 선택한 후 전송 버튼을 누르면 무인 업로드가 완료됩니다.
