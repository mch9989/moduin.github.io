제조 현장에서 설비 증설 투자를 검토할 때 경영진이 가장 먼저 확인하는 지표는 현재 설비의 가동률입니다. 하지만 작업자가 퇴근 전 수기로 작성한 작업일보에는 늘 '가동률 92~95%'가 찍혀 있는 반면, 실제 생산 출하량은 목표치의 70% 수준에 머무르는 괴리가 빈번히 발생합니다.

1. 수기 작업일보의 '가동률 95%'가 허상인 이유

작업자는 설비가 고장 나서 30분 이상 멈춘 대형 비가동만 일지에 기록합니다. 자재 걸림으로 40초 멈췄다 재가동하는 순간 정지(Chokotei), 금형 교체 지연, 또는 설비가 공회전(Idle) 상태로 돌아가며 표준 사이클 타임보다 20% 느리게 생산되는 속도 저하 손실은 수기 일지에 전혀 잡히지 않기 때문입니다.

2. OEE 3대 지표(시간가동률·성능가동률·양품률) 자동 산출 로직

설비의 진짜 생산성을 왜곡 없이 측정하려면 PLC에서 올라오는 가동 상태 접점(Run/Stop/Alarm)과 제품 카운트 펄스(Shot/Cycle Pulse)를 기반으로 설비 종합효율(OEE)을 자동 계산해야 합니다.

OEE = 시간가동률 × 성능가동률 × 양품률
① 시간가동률: 부하시간(조업시간 - 계획정지) 대비 실제 설비가 돌아간 가동시간 비율
② 성능가동률: 가동시간 동안 이론상 생산해야 할 기준 수량(표준 C/T 기준) 대비 실제 생산 수량 비율
③ 양품률: 총 생산 수량 대비 불량을 제외한 순수 양품 수량 비율

3. 순간 정지(Chokotei)와 계획 비가동의 자동 상태 전이 설계

PLC 신호만으로 비가동을 자동 분류할 때는 상태 전이 타이머(Debounce Timer) 로직이 핵심입니다.

  • 계획 비가동 자동 마스킹: 점심시간, 교대 시간, 정기 예방보전(PM) 스케줄은 기준정보 캘린더와 연동하여 설비가 멈춰 있더라도 자동으로 '계획 정지'로 분류해 작업자가 일일이 사유를 입력하는 번거로움을 없앱니다.
  • 순간 정지 vs 고장 비가동 임계치 분리: 설비 정지 신호 발생 후 3분(180초) 이내에 재가동되면 별도 팝업 없이 '순간 정지' 카운트와 누적 시간만 자동 적산하고, 3분을 초과해 멈춰 있을 때만 현장 POP 단말기에 비가동 사유 선택 팝업을 강제 호출합니다.

4. 현업 설비 모니터링 데이터 집계 기준표

측정 요소 PLC 수집 데이터 및 연산 기준
실가동 시간 PLC 자동 운전(Auto-Run) 비트 On 구간의 초 단위 누적 합계
표준 사이클 타임 품목-설비별 마스터에 등록된 이론 사이클 타임(예: 1개당 4.5초)
공회전(Idle) 감지 Run 신호는 On 상태이나 제품 카운트 펄스가 표준 C/T의 3배 이상 입력되지 않는 구간 분리
설비 알람 매핑 PLC 알람 워드(Word) 번지 값을 읽어 [알람코드 마스터]와 자동 매칭하여 원인 자동 기록

수기 데이터를 걷어내고 PLC 펄스 기반의 OEE 산출 체계를 구축하면, "설비를 한 대 더 살 것인가, 아니면 현재 라인의 순간 정지와 속도 저하 15%만 잡아도 증설 없이 목표 물량을 뽑아낼 수 있는가"에 대한 명확한 데이터 기반 의사결정이 가능해집니다.
