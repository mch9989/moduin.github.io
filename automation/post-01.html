C# .NET과 제미나이 API를 활용한 업무 자동화 파이프라인 구축기

작성일: 2026년 11월 5일 · 작성자: moduin

수작업으로 수많은 사진과 파일의 키워드, 설명을 입력하고 외부 서버로 전송하는 일은 많은 리소스를 소모합니다. 본 글에서는 C# .NET 환경에서 제미나이(Gemini) 멀티모달 API를 연동하여 이미지 메타데이터를 자동 생성하고, 안전하게 서버로 전송하는 시스템 아키텍처를 소개합니다.

1. 파이프라인 개요

전체 처리 흐름은 아래와 같습니다:

1) 로컬 디렉터리 이미지 스캔 → 2) 기존 로컬 DB 중복 분석 여부 캐시 조회 → 3) 미분석 이미지의 제미나이 API 호출 및 태그 추출 → 4) 결과 DB 적재 → 5) SFTP 프로토콜을 통한 원격 서버 자동 전송

2. 제미나이 API 비동기 호출 구현

수백 장의 이미지를 순차 동기식으로 처리하면 네트워크 병목이 발생합니다. Task 기반의 병렬 제어와 세마포어(SemaphoreSlim)를 적용하여 API Rate Limit을 준수하면서도 처리 속도를 극대화했습니다.

// HttpClient를 통한 Gemini API 비동기 요청 예시 구조
var requestUri = $"https://generativelanguage.googleapis.com/v1beta/models/gemini-pro-vision:generateContent?key={apiKey}";
var payload = new { /* Base64 이미지 및 프롬프트 정의 */ };
// 세마포어를 통해 동시 요청 수 제어
await semaphore.WaitAsync();
try {
    var response = await httpClient.PostAsJsonAsync(requestUri, payload);
    // 응답 JSON 파싱 및 태그 정제 로직
} finally {
    semaphore.Release();
}

3. 성능 및 비용 최적화

가장 핵심적인 부분은 이미 분석된 이미지를 다시 API로 쿼리하지 않도록 로컬 SQLite나 MS-SQL에 해시값과 메타데이터를 저장하는 캐싱 계층을 둔 것입니다. 이를 통해 불필요한 API 비용을 0원으로 유지할 수 있었습니다.
